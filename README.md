Judul Project
“e-Kantin Sekolah”
Aplikasi digital untuk pemesanan makanan kantin sekolah yang cepat, tertib, dan higienis.

Deskripsi Project
e-Kantin Sekolah adalah aplikasi berbasis mobile/web yang memungkinkan siswa dan guru:
•	Melihat menu kantin
•	Memesan makanan/minuman sebelum jam istirahat
•	Mengurangi antrean panjang
•	Mendukung sistem kantin sehat & modern
Aplikasi ini juga membantu penjual kantin dalam mengatur pesanan dan stok.

Peran & Tugas Masing-Masing Jurusan
1. DKV (Desain Komunikasi Visual)
Fokus: Desain visual & pengalaman pengguna
Tugas DKV:
•	Membuat identitas visual aplikasi
o	Logo e-Kantin
o	Warna & tipografi
•	Mendesain UI/UX aplikasi
o	Tampilan menu
o	Halaman pemesanan
o	Notifikasi pesanan
•	Membuat icon & ilustrasi makanan
•	Mendesain materi promosi
o	Poster digital
o	Konten media sosial
o	Banner launching aplikasi
•	Menentukan konsep visual kampanye kantin sehat
📌 Output DKV:
•	Logo & brand guideline
•	Desain tampilan aplikasi (mockup)
•	Materi promosi visual

2. RPL (Rekayasa Perangkat Lunak)
Fokus: Pengembangan sistem & aplikasi
Tugas RPL:
•	Mengembangkan aplikasi e-Kantin (web)
•	Membuat fitur utama:
o	Login siswa, guru & penjual
o	Daftar menu & harga
o	Sistem pemesanan & antrean
o	Notifikasi pesanan siap
o	Laporan penjualan
•	Mengelola database
o	Data user
o	Data menu
o	Data transaksi
•	Mengintegrasikan desain dari DKV
•	Testing & maintenance aplikasi
📌 Output RPL:
•	Aplikasi e-Kantin yang berjalan
•	Database & sistem admin
•	Dokumentasi sistem


3. PSPT (Produksi Siaran Program Televisi / Broadcasting)
Fokus: Konten audiovisual & publikasi
Tugas PSPT:
•	Membuat konsep video promosi aplikasi
•	Menyusun naskah & storyboard
•	Produksi video:
o	Video iklan e-Kantin
o	Video tutorial cara pakai aplikasi
o	Video profil kantin sekolah
•	Pengambilan gambar & audio
•	Editing video & sound
•	Menyiapkan konten untuk:
o	TV sekolah
o	Media sosial
o	Presentasi launching aplikasi
📌 Output PSPT:
•	Video promosi utama
•	Video tutorial penggunaan aplikasi
•	Konten audiovisual untuk publikasi

Alur Kolaborasi Project
1.	Diskusi konsep & kebutuhan kantin sekolah
2.	DKV mendesain visual & UI/UX
3.	RPL mengembangkan aplikasi berdasarkan desain
4.	PSPT memproduksi konten video promosi & tutorial
5.	Integrasi konten ke dalam aplikasi
6.	Launching & presentasi project

Manfaat Project

PROPOSAL PROJECT KOLABORASI
APLIKASI KANTIN SEKOLAH “e-KANTIN”

I. Latar Belakang
Kantin sekolah merupakan fasilitas penting yang menunjang aktivitas belajar siswa. Namun, dalam praktiknya sering muncul beberapa permasalahan seperti antrean panjang, keterlambatan pelayanan, dan kurangnya informasi menu yang tersedia. Di era digital, pemanfaatan teknologi dapat menjadi solusi untuk meningkatkan efisiensi dan kenyamanan layanan kantin sekolah.
Oleh karena itu, diperlukan sebuah aplikasi kantin sekolah (e-Kantin) yang mampu mengintegrasikan sistem pemesanan makanan secara digital. Project ini dirancang sebagai bentuk kolaborasi antar jurusan DKV, RPL, dan PSPT, sehingga setiap jurusan dapat menerapkan kompetensinya sesuai bidang masing-masing dan menciptakan sebuah produk yang bermanfaat bagi lingkungan sekolah.
II. Tujuan Project
1.	Membuat aplikasi kantin sekolah berbasis digital
2.	Mengurangi antrean dan meningkatkan efisiensi pelayanan kantin
3.	Melatih kerja sama lintas jurusan
4.	Menghasilkan karya nyata sebagai portofolio siswa
5.	Menerapkan pembelajaran berbasis project (Project Based Learning)
III. Nama dan Konsep Project
Nama Project:
e-Kantin Sekolah
Konsep:
Aplikasi pemesanan makanan dan minuman kantin sekolah yang praktis, modern, dan mudah digunakan oleh siswa, guru, serta pengelola kantin.
IV. Ruang Lingkup Project
•	Aplikasi pemesanan makanan (mobile/web)
•	Desain visual dan UI/UX aplikasi
•	Konten video promosi dan tutorial aplikasi
•	Media publikasi dan presentasi project
V. Pembagian Tugas Tiap Jurusan
A. Jurusan DKV (Desain Komunikasi Visual)
Peran: Desain visual dan komunikasi aplikasi
Tugas:
1.	Membuat logo dan identitas visual e-Kantin
2.	Menentukan warna, tipografi, dan gaya visual
3.	Mendesain UI/UX aplikasi (mockup)
4.	Membuat ikon, ilustrasi, dan elemen grafis
5.	Mendesain media promosi (poster, banner, feed media sosial)
Output:
•	Logo dan brand guideline
•	Desain tampilan aplikasi
•	Materi promosi visual

B. Jurusan RPL (Rekayasa Perangkat Lunak)
Peran: Pengembangan sistem dan aplikasi
Tugas:
1.	Membangun aplikasi e-Kantin berbasis web/mobile
2.	Membuat fitur:
o	Login pengguna
o	Daftar menu dan harga
o	Sistem pemesanan dan antrean
o	Notifikasi pesanan
o	Laporan transaksi
3.	Mengelola database
4.	Mengintegrasikan desain DKV ke dalam aplikasi
5.	Melakukan pengujian dan perbaikan sistem
Output:
•	Aplikasi e-Kantin yang berfungsi
•	Database dan sistem admin
•	Dokumentasi teknis

C. Jurusan PSPT (Produksi Siaran Program Televisi)
Peran: Produksi konten audiovisual dan publikasi
Tugas:
1.	Menyusun konsep video promosi aplikasi
2.	Membuat naskah dan storyboard
3.	Produksi video:
o	Video iklan e-Kantin
o	Video tutorial penggunaan aplikasi
4.	Pengambilan gambar dan audio
5.	Editing video dan audio
6.	Menyiapkan konten untuk media sosial dan presentasi
Output:
•	Video promosi e-Kantin
•	Video tutorial penggunaan aplikasi
•	Konten audiovisual pendukung

VI. Alur Pelaksanaan Project
1.	Diskusi konsep dan perencanaan project
2.	Pembuatan desain visual oleh DKV
3.	Pengembangan aplikasi oleh RPL
4.	Produksi konten video oleh PSPT
5.	Integrasi seluruh hasil project
6.	Uji coba aplikasi
7.	Presentasi dan launching project
VII. Waktu Pelaksanaan
Durasi project: 8–12 minggu
Minggu	Kegiatan
1	Perencanaan & pembagian tugas
2–3	Desain visual (DKV)
3–6	Pengembangan aplikasi (RPL)
5–7	Produksi video (PSPT)
8	Integrasi & uji coba
9	Presentasi & evaluasi
VIII. Penutup
Project e-Kantin Sekolah ini diharapkan dapat menjadi sarana pembelajaran kolaboratif antar jurusan serta menghasilkan produk digital yang bermanfaat bagi lingkungan sekolah. Melalui project ini, siswa dapat mengembangkan keterampilan teknis, kreativitas, dan kerja tim sesuai dengan kebutuhan dunia industri.
